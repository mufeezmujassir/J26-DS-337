# Stage 12.4G Limitations and Activation Gate

The 72-query sample has 23 climate-source identities, but district-proxy evidence still dominates (64/72). Only eight selected queries have attraction-coordinate climate evidence, so coordinate-specific subgroup conclusions may remain imprecise. Shared district climatology creates dependence even with many attractions. Reviewer capacity is 1,728 independent judgments before any disagreement adjudication. The chosen target is feasibility-based and does not guarantee power.

Historical climatology is not a live forecast and cannot establish surf, flood, current, landslide, wildlife, access, or operational safety. The shadow latency sample is small and includes one cold model load. Group Emotion is unavailable.

Production activation is outside Stage 12.4G. It requires completed genuine reviews, verified adjudication, a protocol-valid decision, a separate explicit governance decision, and additional performance/security review. All production-ranking behavior remains unchanged.

No migration was required. Existing evaluation tables are reused. Because the legacy status column is `VARCHAR(50)` and the mandated public status is 51 characters, the column stores `ENGINEERING_COMPLETED_VALIDATION_PENDING`; the exact `STAGE12_4G_ENGINEERING_COMPLETED_VALIDATION_PENDING` value is persisted in run metadata and the final report without truncation.
